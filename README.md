# PrototipeSmart: SmartFurniture

Prototipo web 100 % offline (React + TypeScript + Three.js) para diseñar, escalar y optimizar el corte de muebles de melamina. Proyecto de **Funciones y Matrices, Unidad 3 (INACAP)**. Entrega: 1 de diciembre de 2026.
